# Form Validation Test

<!-- description -->

This is a form validation demo built using HTML, CSS, and JavaScript.
An interactive registration/feedback form featuring dynamic client-side field validation.

## Features (What is validated)

- **Username**: required field, minimum of 3 characters, letters only.
- **Email**: format correctness check (presence of `@`, dot, valid domain).
- **Password**: minimum of 8 characters, must contain at least one digit and one uppercase letter.
- **Confirm Password**: automatic matching check against the primary password.
- **Interactivity**: real-time error highlighting (red/green colors) and submit button disabling until all errors are fixed.

## Technologies

- **HTML5**: semantic markup, built-in validation attributes.
- **CSS3**: custom styling, error appearance animations, mobile responsive design.
- **JavaScript (ES6+)**: regular expressions (RegEx) for checks, handling `input` and `submit` events.
